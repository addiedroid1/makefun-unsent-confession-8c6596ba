One two-part micro-confession, written exactly as it was typed and never sent: a To: line and the unsent message itself.

> To: Gran
> I ate the last biscuit from your tin the day you died and never told anyone. I still lift the lid when I visit, like it might be full again.

## Run it

```sh
node main.ts
```

It writes the confession to `/output/entry.txt` (149 characters).
